# Design System

## Design Philosophy

Ingredo should feel:

- Warm
- Calm
- Helpful
- Practical

Avoid:

- Corporate dashboards
- Excessive complexity
- Tiny touch targets

## Core UX Principles

### Shopping Is Not A Todo List

Do not use checkboxes.

Users are shopping, not completing tasks.

### Recently Purchased

Purchased items move to:

- Recently Purchased

This area acts as:

- Shopping history
- Undo mechanism
- Quick-add library

### One-Handed Usage

Most shopping interactions should be possible with one hand.

### Fast Actions

Reduce taps whenever possible.

### Meal Planning First

Meal planning should be a first-class feature.

Recipes support meal planning.

Shopping supports meal planning.

## Navigation

Recommended tabs:

- Recipes
- Week
- Shop
- Settings
