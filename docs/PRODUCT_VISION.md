# Product Vision

## Mission

Ingredo helps households answer one question:

'What are we eating this week, and what do we need to buy?'

The application combines meal planning, recipes, and shopping into one workflow.

## Problem

Many households use:

- One app for shopping lists
- One app for recipes
- A calendar or notes app for meal planning

Information is scattered across multiple tools.

Ingredo brings everything together.

## Core Value

Plan meals.
Generate ingredients.
Shop efficiently.

## Target Audience

- Couples
- Families
- Frequent home cooks
- Meal planners

## Success Criteria

A user should be able to:

1. Plan a week of meals
2. Generate a shopping list
3. Complete shopping
4. Reuse previous shopping habits

with minimal effort.
