# User Stories

## Recipes

As a user, I want to create a recipe so that I can save meals I enjoy making.

As a user, I want to edit a recipe so that I can improve it over time.

As a user, I want to scale a recipe so that ingredient quantities match the number of servings.

## Shopping

As a user, I want to generate a shopping list from a recipe.

As a user, I want to generate a shopping list from a weekly meal plan.

As a user, I want to add manual shopping items.

As a user, I want purchased items moved into Recently Purchased.

As a user, I want to restore items from Recently Purchased.

## Meal Planning

As a user, I want to assign recipes to days of the week.

As a user, I want to view my week at a glance.

As a user, I want to generate shopping lists from my plan.

## Household Sharing

As a household member, I want to see shopping changes made by others.

As a household member, I want to share recipes and meal plans.
